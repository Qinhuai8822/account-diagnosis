# account-diagnosis

自媒体账号快速诊断、选题规划与文案生产的一体化 Skill，适用于任何平台（抖音 / B站 / 小红书 / 视频号 / 快手 / 公众号等）与任何领域。

## 这是什么

一套平台无关、领域无关的账号运营方法论，以 Agent Skill（SKILL.md + 参考文档 + 脚本）形式封装。把它放进任何支持 Skill 机制的 AI 助手的技能目录，AI 即可按标准流程执行：

```
①数据采集 → ②对标锁定 → ③自我诊断 → ④一周选题排期 → ⑤周频复盘闭环
                                                      ↓
              ⑥文案生产链路：选题 → 爆款结构拆解 → 四段式生成
                            → 去AI味（必须）→ 违禁词检测（必须）→ 一稿多发
```

## 核心特性

- **平台无关**：内置 8 个平台映射卡（抖音 / B站 / 小红书 / 视频号 / 快手 / 公众号 / TikTok / YouTube，其中前三者为实战验证级）；其他平台按「找后台 → 找权重指标 → 找内容形态」三步法 10 分钟自建映射卡
- **领域无关**：流程不绑定内容品类，换赛道只改关键词与内容引擎
- **可降级执行**：数据源四级降级（后台实抓 → 公开数据 → 用户截图/导出 → 标注估算），没有浏览器自动化也能跑
- **零环境绑定**：不依赖任何特定付费 API 或脚本路径；自带聚合脚本，兼容常见编码坑
- **自带避坑清单**：浏览器自动化的 7 个常见技术坑（进程回收 / SPA 导航 / httpOnly Cookie / 编码等）已写入文档

## 目录结构

```
account-diagnosis/
├── SKILL.md                          # 六阶段主流程
├── references/
│   ├── platform-guide.md             # 平台数据采集路径 / 权重指标差异表 / 敏感词替换表 / 技术坑清单
│   ├── benchmark-playbook.md         # 对标锁定：信号判读 + 六项对标档案 + 头部账号反查技巧
│   ├── copywriting-pipeline.md       # 文案生产链路：结构拆解 / 四段式脚本 / 去AI味 / 合规检测 / 一稿多发
│   └── report-templates.md           # 诊断报告 / 周报 / 选题排期模板 + 执行检查清单
└── scripts/
    └── aggregate_benchmarks.py       # 对标聚合工具（按作者聚合搜索结果，输出均赞/藏赞比/评赞比）
```

## 安装

1. 下载本仓库（`Code → Download ZIP` 或 `git clone`）
2. 将 `account-diagnosis/` 文件夹整体放入你的 AI 助手的技能目录（如 `~/.workbuddy/skills/` 或其他支持 Agent Skills 的目录）
3. 重启 / 重载技能列表即生效

## 使用示例

对 AI 说：

- 「帮我诊断我的小红书美妆账号」→ 触发全流程，产出对标拆解 + 差距分析 + 一周排期
- 「给这个号找 3 个对标并做选题计划」→ 执行阶段二 + 阶段四
- 「按排期把周一的文案写出来」→ 执行阶段六文案生产链路

## 脚本用法

```bash
python scripts/aggregate_benchmarks.py <搜索结果json文件...> --top 10
```

输入为平台搜索接口返回的 JSON 文件（兼容 UTF-8 / UTF-16 编码），输出按作者聚合的作品数、总赞、均赞、藏赞比、评赞比排行。
