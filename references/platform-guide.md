# 平台数据采集指南（Platform Guide）

适用于抖音/B站/小红书三大平台，其他平台按同样思路映射（找后台 → 找权重指标 → 找内容形态）。

## 一、各平台数据采集路径

### 抖音
- 后台：creator.douyin.com/creator-micro/home（需登录，扫码）
- 抓取项：
  - 数据总览：播放量、互动率、完播率、2秒跳出率、粉丝净增、作品数
  - 内容管理页（creator-micro/content/manage）：逐条作品标题/播放/赞/评/藏/发布时间
  - 粉丝数据页：性别/年龄/地域分布（<300粉可能未解锁，列为运营目标）
- 权重指标：完播率、2秒跳出率、互动率（点赞评藏转的加权）
- 流量逻辑：48小时推荐池，爆发快衰退快
- 发布时段：19:00-19:05 固定档实测有效；一天多条间隔≥3小时，宁缺勿扎堆
- 标题策略：悬念+具体数字短句（"90%的人第一炷香就插错了"）

### B站
- 后台：member.bilibili.com/platform/home（需登录）
- 抓取项：
  - 首页：近7日播放/评论/弹幕/点赞/分享/收藏/投币、粉丝总数与变化、收益
  - 作品列表：可用UID查公开API/第三方工具（播放/弹幕/评论/时长/发布时间）
  - UID获取：登录态下访问 api.bilibili.com/x/web-interface/nav（返回 mid/uname/level）
- 权重指标：播放/粉比（账号潜力）、弹幕互动、投币（B站特有高价值）
- 流量逻辑：推荐池 + **搜索长尾**（一条好视频半年后仍在引流）——标题必须按"可搜索"标准做，含领域关键词
- 内容形态：5-20分钟深度内容，抖音短口播需扩写成"加密度版"
- 标题策略：栏目前缀【系列名-XX】+ 悬念问句/信息量长标题
- 发布时段：12:00-18:00，周更2-3条
- 合集=栏目=追更理由，系列化是B站涨粉核心架构

### 小红书
- 后台：creator.xiaohongshu.com/new/home（需登录）
- 抓取项：
  - 首页笔记数据总览：曝光数/观看数/封面点击率/完播率/赞/评/藏/分享/净涨粉/主页访客
  - 笔记管理：逐条笔记数据
- 权重指标：**收藏+评论**（不是点赞）、封面点击率
- 流量逻辑：搜索长尾为主，账号标签由历史笔记决定——新号前10篇决定算法认知
- 内容形态：图文为主（AI插画+大字封面卡片），视频为辅
- 封面策略：大字标题+统一色调模板，封面即生死；标题必含搜索关键词，正文前两行复现
- 发布时段：12:00 或 21:00，图文可日更
- 冷启动公式：细分切口 + 封面大字 + 单篇只卡1个搜索词 + 发布后2小时内回复全部评论

| 维度 | 抖音 | B站 | 小红书 |

## 三、合规基线与敏感词替换表

- 固定免责声明（按平台风格适配）："以上内容仅供娱乐参考，中华传统文化博大精深，理性看待"（命理/民俗类必带；其他领域换成对应专业免责）
- 通用排查：绝对化断言（"一定"→"有望"）、医疗暗示（禁止）、引导私下交易（禁外部引流词）
- 敏感赛道（命理/风水/玄学类）替换表：
  - 算命 → 传统文化 / 自我认知工具
  - 风水 → 居住讲究 / 环境心理学
  - 改运/转运 → 调整习惯 / 能量状态
  - 命理 → 民俗文化 / 传统智慧
- 小红书审核最严，敏感赛道标题正文全程用替换词；发布前有违禁词检测工具的先过一遍

## 四、技术坑清单（浏览器自动化采集时）

1. **进程树回收**：浏览器必须以宿主环境的持久后台任务方式启动，否则随命令结束被回收——"登录页几秒自动关闭"的最常见根因
2. **配置目录路径**：浏览器用户数据目录用无空格无特殊字符的路径
3. **SPA子路由**：创作中心类站点子路由直接跳转常渲染为空，需回首页用 JS click 菜单导航
4. **httpOnly cookie**：登录态 cookie（如 SESSDATA）页面 JS 读不到，判断登录态看 URL 是否跳登录页，或导航到官方接口页读返回 JSON
5. **编码**：结果落盘为 UTF-8 文件再读，不要直接读控制台输出；PowerShell 重定向输出可能是 UTF-16，读取时按 utf-8-sig / utf-16 依次尝试
6. **CSP 限制**：在页面上下文内 fetch 跨域接口可能被 CSP 拦截超时，替代法：直接导航标签页到接口 URL 后读 document.body
7. **数据源降级顺序**：后台实抓 > 公开数据页 > 用户提供截图/导出 > 基于已有信息估算（报告中标注"估算"）
