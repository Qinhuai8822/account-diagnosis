# 平台数据采集指南（Platform Guide）

覆盖 8 个平台的映射卡：抖音/B站/小红书（实战验证级）+ 视频号/快手/公众号/TikTok/YouTube（标准映射卡）。其他平台按第「五」节自查三步法迁移（找后台 → 找权重指标 → 找内容形态）。

## 一、各平台数据采集路径

### 抖音
- 后台：creator.douyin.com/creator-micro/home（需登录，扫码）
- 抓取项：
  - 数据总览：播放量、互动率、完播率、2秒跳出率、粉丝净增、作品数
  - 内容管理页（creator-micro/content/manage）：逐条作品标题/播放/赞/评/藏/发布时间
  - 粉丝数据页：性别/年龄/地域分布（<300粉可能未解锁，列为运营目标）
- 权重指标：完播率、2秒跳出率、互动率（点赞评藏转的加权）
- 流量逻辑：48小时推荐池，爆发快衰退快
- 发布时段：19:00-19:05 固定档实测有效；一天多条间隔≥3小时，宁缺勿扎堆
- 标题策略：悬念+具体数字短句（"90%的人第一炷香就插错了"）

### B站
- 后台：member.bilibili.com/platform/home（需登录）
- 抓取项：
  - 首页：近7日播放/评论/弹幕/点赞/分享/收藏/投币、粉丝总数与变化、收益
  - 作品列表：可用UID查公开API/第三方工具（播放/弹幕/评论/时长/发布时间）
  - UID获取：登录态下访问 api.bilibili.com/x/web-interface/nav（返回 mid/uname/level）
- 权重指标：播放/粉比（账号潜力）、弹幕互动、投币（B站特有高价值）
- 流量逻辑：推荐池 + **搜索长尾**（一条好视频半年后仍在引流）——标题必须按"可搜索"标准做，含领域关键词
- 内容形态：5-20分钟深度内容，抖音短口播需扩写成"加密度版"
- 标题策略：栏目前缀【系列名-XX】+ 悬念问句/信息量长标题
- 发布时段：12:00-18:00，周更2-3条
- 合集=栏目=追更理由，系列化是B站涨粉核心架构

### 小红书
- 后台：creator.xiaohongshu.com/new/home（需登录）
- 抓取项：
  - 首页笔记数据总览：曝光数/观看数/封面点击率/完播率/赞/评/藏/分享/净涨粉/主页访客
  - 笔记管理：逐条笔记数据
- 权重指标：**收藏+评论**（不是点赞）、封面点击率
- 流量逻辑：搜索长尾为主，账号标签由历史笔记决定——新号前10篇决定算法认知
- 内容形态：图文为主（AI插画+大字封面卡片），视频为辅
- 封面策略：大字标题+统一色调模板，封面即生死；标题必含搜索关键词，正文前两行复现
- 发布时段：12:00 或 21:00，图文可日更
- 冷启动公式：细分切口 + 封面大字 + 单篇只卡1个搜索词 + 发布后2小时内回复全部评论

### 视频号（微信）
- 后台：channels.weixin.qq.com/platform（视频号助手，需微信扫码）
- 抓取项：
  - 创作者中心：近7日播放/点赞/评论/转发/关注转化、主页访问、直播数据
  - 单条作品：播放/完播/转发/点赞/评论（数据维度较抖音少，导出功能有限）
- 权重指标：**转发**（社交裂变核心）+ 完播率 + 点赞（好友点赞会展示给其朋友，链式传播）
- 流量逻辑：社交推荐（朋友赞过/转发）+ 算法推荐混合；朋友圈与群聊转发是第一引擎
- 内容形态：60s-3min；用户年龄偏高，情感/生活/知识科普类表现强；微信生态内闭环
- 标题策略：口语化+情绪共鸣（"转给家里爸妈看看"类天然转发钩子）
- 发布时段：19:00-22:00 晚间档；结合目标用户作息
- 审核特点：微信生态审核偏严（医疗/金融/引导站外交易红线多）；**私域转化天然顺畅**（可引导至公众号/企业微信）

### 快手
- 后台：cp.kuaishou.com（快手创作者中心，需登录）
- 抓取项：
  - 首页数据总览：播放/点赞/评论/分享/关注转化、粉丝总数与净增
  - 作品管理：逐条作品数据
- 权重指标：完播率 + **互动率（评论/"老铁"式互动）** + 粉丝粘性（关注页流量占比高）
- 流量逻辑：普惠算法（扶持素人）+ 关注分发占比显著高于抖音——**私域与粉丝粘性是快手特色**
- 内容形态：真实人设感强、下沉市场友好、直播转化能力强；过度精致反而减分
- 标题策略：接地气口语、第一人称叙事
- 发布时段：18:00-23:00
- 审核特点：中等；方言/地域内容友好

### 公众号（微信公众平台）
- 后台：mp.weixin.qq.com（需登录）
- 抓取项：
  - 内容分析：阅读/在看/点赞/分享/留言、送达率、完读率、常读用户分析
  - 用户分析：净增/取关、性别/地域/终端分布
  - 流量来源：会话/朋友圈/看一看/**搜一搜**（搜索长尾）
- 权重指标：**分享+在看**（驱动进入"看一看"推荐）、打开率、完读率、涨粉/取关比
- 流量逻辑：无算法推荐池（除看一看/搜一搜），靠社交裂变与**搜一搜搜索长尾**——标题按搜索词做
- 内容形态：长图文，排版质量即门面（分段/配图/小标题）
- 标题策略：搜索词+数字/悬念，摘要栏复现关键词；避免过度标题党（微信会限制）
- 发布时段：早7-9 或 晚21-22
- 审核特点：最严之一（诱导分享/外链/金融医疗红线）；胜在**私域资产沉淀**，适合做信任转化的终点站

### TikTok（海外）
- 后台：TikTok Studio（tiktok.com/tiktokstudio，或 App 内创作者工具）
- 抓取项：
  - Overview：Views/Watch time/Average watch time/Followers 净增
  - 单条视频：播放/完整观看率/平均观看时长/赞评转/收藏
- 权重指标：**Watch time 与完整观看率（completion rate）**、重播（rewatch）、分享、互动率
- 流量逻辑：For You 推荐池按**语言与地区分区**——账号的网络环境与语言决定初始分发市场；新号前几条内容定标签（类似小红书前10篇逻辑）
- 内容形态：15s-3min；前3秒 hook 全球通用；本地化语言+文化适配是门槛
- 标签策略：标签+搜索 SEO 权重持续上升，标题带目标市场搜索词
- 发布时段：按**目标市场的时区**计算，非本机时区
- 风险提示：网络环境需与目标市场一致（IP/语言/时区不匹配会限流）；注意各国数据与广告披露合规

### YouTube
- 后台：studio.youtube.com（YouTube Studio，Google 账号登录）
- 抓取项：
  - 频道仪表盘：Views/Watch time/Subscribers 净增
  - Reach 页：**CTR（缩略图点击率）**、Impressions、流量来源（搜索/推荐/外部）
  - Engagement 页：平均观看时长、留存曲线（找到观众流失的精确时间点）
- 权重指标：**CTR + 平均观看时长（留存）**——两者相乘决定推荐量；观看时长（长视频）与 swipe-through（Shorts）逻辑不同
- 流量逻辑：**搜索长尾全球最强**（背靠 Google 搜索，一条好视频可引流数年）+ 推荐池；系列播放列表提升会话时长
- 内容形态：8-20min 深度长视频 + Shorts 双轨；章节（Chapters）与字幕提升搜索命中
- 标题策略：标题与缩略图是两大杠杆——标题给搜索词，缩略图给情绪
- 发布时段：按目标市场时区；周更1-3条常态
- 变现：广告分成/频道会员/联盟营销；深度内容商单价值高

## 三、合规基线与敏感词替换表

- 固定免责声明（按平台风格适配）："以上内容仅供娱乐参考，中华传统文化博大精深，理性看待"（命理/民俗类必带；其他领域换成对应专业免责）
- 通用排查：绝对化断言（"一定"→"有望"）、医疗暗示（禁止）、引导私下交易（禁外部引流词）
- 敏感赛道（命理/风水/玄学类）替换表：
  - 算命 → 传统文化 / 自我认知工具
  - 风水 → 居住讲究 / 环境心理学
  - 改运/转运 → 调整习惯 / 能量状态
  - 命理 → 民俗文化 / 传统智慧
- 小红书审核最严，敏感赛道标题正文全程用替换词；发布前有违禁词检测工具的先过一遍

## 四、技术坑清单（浏览器自动化采集时）

1. **进程树回收**：浏览器必须以宿主环境的持久后台任务方式启动，否则随命令结束被回收——"登录页几秒自动关闭"的最常见根因
2. **配置目录路径**：浏览器用户数据目录用无空格无特殊字符的路径
3. **SPA子路由**：创作中心类站点子路由直接跳转常渲染为空，需回首页用 JS click 菜单导航
4. **httpOnly cookie**：登录态 cookie（如 SESSDATA）页面 JS 读不到，判断登录态看 URL 是否跳登录页，或导航到官方接口页读返回 JSON
5. **编码**：结果落盘为 UTF-8 文件再读，不要直接读控制台输出；PowerShell 重定向输出可能是 UTF-16，读取时按 utf-8-sig / utf-16 依次尝试
6. **CSP 限制**：在页面上下文内 fetch 跨域接口可能被 CSP 拦截超时，替代法：直接导航标签页到接口 URL 后读 document.body
7. **数据源降级顺序**：后台实抓 > 公开数据页 > 用户提供截图/导出 > 基于已有信息估算（报告中标注"估算"）

## 五、其他平台自查三步法（通用迁移）

本指南未覆盖的平台（X/Twitter、知乎、微博、Instagram、网易云音乐、B站专栏、知识星球等），用三步法 10 分钟内自建映射卡，再走六阶段主流程：

1. **找后台**：平台名 + "创作者中心/Creator Studio/创作服务平台"，找到官方后台地址与数据导出功能
2. **找权重指标**：优先级判断——哪个指标是该平台推荐算法的核心信号？通用规律：
   - 短视频平台看完播/完看率；图文社区看收藏/评论（存用价值）；长视频/搜索型平台看 CTR×观看时长
   - 验证法：找 3 个该平台的高粉账号，看它们的共同内容特征反推权重（如某平台高粉账号全在拼转发 → 转发是核心权重）
3. **找内容形态**：该平台用户消费什么形态（口播/图文/长文/音频）？对标账号怎么定标题与封面？

产出一张与上文格式一致的映射卡（后台/抓取项/权重指标/流量逻辑/内容形态/标题策略/发布时段/审核特点八要素），即可纳入六阶段流程复用。

> 提示：海外平台（TikTok/YouTube/X/Instagram）注意时区逻辑按目标市场计算、网络环境与目标市场一致、以及当地数据与广告披露合规。
