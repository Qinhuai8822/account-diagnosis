## 二、周复盘报告模板（周频）

```
═══════════════════════════════════
 <账号名> · 周报 YYYYMMDD
═══════════════════════════════════

一、本周数据 vs 上周对比表（核心指标逐项：数值/环比/判定）
二、最佳作品分析：为什么好（钩子/选题/时段），可复制什么
三、最差作品分析：断在哪一环（曝光→点击→完播→互动→吸粉）
四、选题类型效果榜：按收藏/互动比排序，标出扩产与淘汰
五、发布纪律检查：时段执行/重复发布/合集维护 ✅❌逐项
六、下周 7 天选题排期（五要素齐全）
七、行动建议 ≤3条
```

## 三、五维自我诊断方法

| 维度 | 检查问题 | 数据依据 |
|------|---------|---------|
| 定位 | 一句话定位是什么？有没有对标那样的记忆点（地域/清单/人格）？ | 主页简介+内容一致率 |
| 内容质量 | 已验证的爆款钩子是什么？是否公式化复制了？内容引擎有没有栏目化？ | 高播放作品反推+合集结构 |
| 数据表现 | 按平台权重指标找短板（见 platform-guide 差异表） | 漏斗逐环：曝光→点击→完播→互动→吸粉 |
| 粉丝画像 | 我的粉丝与对标粉丝结构错配吗？ | 后台画像（性别/年龄/地域） |
| 运营纪律 | 时段固定？合集维护？评论区主动回复前20条？ | 发布时间记录+评论区观察 |

诊断核心逻辑：**流量不是问题的账号，问题在转化**（播放高吸粉低=缺关注钩子/合集/系列感）；**流量本身低的账号**，先查运营bug（重复发布、时段扎堆、账号标签混乱），再查内容钩子。

## 四、一周选题排期模板

每条选题五要素：

```
周X M/DD |【栏目编号】选题名 | 内容形式 | 标题方向（含1个搜索关键词）| 钩子类型
```

配比公式：**70% 已验证内容引擎 + 20% 节点热点 + 10% 实验支线**。

钩子类型库（按领域适配套用）：
- 悬念式："你绝对想不到..."｜痛点式："你是不是也..."
- 反常识："99%的人不知道..."｜干货预告："今天教你一招..."
- 对号入座："属X/做X工作的注意了..."｜节点切入：节气/节日/热点事件

排期纪律：
- 更新频率与时段固定（宁可少更不可乱更）；一天多条间隔≥3小时
- 同文案/同选题绝不重复发布（已验证的高频错误）
- 新栏目必须配合集/编号，发布后主动回复前20条评论
- 每条选题过敏感词替换表 + 免责声明

## 五、周频复盘闭环

1. 固定每周同一时间（建议周日晚，一周数据已完整）重跑数据采集+五维诊断
2. 对比上周四件事：涨粉变化 / 高价值指标最高的选题类型 / 发布纪律执行 / 有无重复发布
3. 淘汰规则：高价值指标（藏赞比≥0.8 或平台对应物）的选题类型扩产；连续2周无改善的类型淘汰
4. 结论回写选题池：选题池 → 排期 → 数据 → 反哺选题池
5. 宿主环境支持定时任务时，把"数据采集+对比诊断+下周排期+报告"配置为周频自动化

## 六、执行检查清单（每次诊断过一遍）

- [ ] 自账号数据已采集（≥7天窗口，数据源已标注）
- [ ] 2-3个对标已锁定，六项档案齐全
- [ ] 三列对比表已产出（指标/同类/对标）
- [ ] "不为清单"已列出（含运营bug排查）
- [ ] 机会点≤3条且已排序
- [ ] 一周排期五要素齐全，配比70/20/10
- [ ] 全部选题过敏感词替换+免责声明
- [ ] 复盘时间已约定（周频固定）
- [ ] 交付物最后一行回答："最大瓶颈一个+本周先做哪一件事"
