# 文案生产链路（Copywriting Pipeline）

将选题排期表逐条转化为可发布文案的标准化链路。适用于口播视频脚本与图文笔记，任何领域通用。

## 链路总览

```
①选题输入 → ②爆款结构拆解（可选） → ③文案生成 → ④去AI味改写（必须）
  → ⑤违禁词/合规检测（必须） → ⑥一稿多发（可选） → 交付
```

②⑥为可选环节；④⑤任何一条文案都必须过，跳过视为未完成。

## ① 选题输入

- 来源：阶段四排期表（每日一条，含选题/形式/标题方向/钩子类型）
- 单条文案开工前确认四要素：平台、内容形式（口播视频/图文/长视频）、目标关键词、钩子类型

## ② 爆款结构拆解（可选但强烈推荐）

有对标爆款素材（链接/文案/逐字稿）时，先拆再写，不凭空创作：

1. **逐秒拆钩子**：开头 2 秒说了什么（反常识/数字/悬念/身份代入哪一类）
2. **情绪曲线**：划分段落，标注每段功能（钩子→铺垫→干货1→干货2→反转→引导）
3. **互动埋点**：找出口播者在哪里引导评论/收藏/关注，用什么话术
4. **复刻规则**：借结构不抄内容——同一段落功能、钩子类型、节奏配比可用，具体表述必须原创

无素材时跳过本步，直接按下方"四段式"生成。

## ③ 文案生成规范

### 口播脚本四段式（60-75s 标准）

```
[钩子 0-3s] 反常识数字/悬念句，禁止"大家好/今天给大家分享"
[主体 3-50s] 干货清单或叙事，每 10-15s 一个信息点，
  用 [停顿] [比划] [放慢] 等节奏标记控制完播
[引导 50-60s] 收藏理由（"怕忘记先收藏"）+ 关注理由（系列预告）
  + 评论区提问（降低互动门槛的具体问题）
[合规] 免责声明 + 平台适用话题标签
```

### 图文笔记三件套（小红书/公众号）

1. **封面大字**：≤10 字核心利益点，一号字体
2. **标题**：含搜索关键词 + 数字或情绪词，≤20 字
3. **正文**：前两行复现关键词（搜索权重最高），主体用清单体/步骤体，结尾抛互动问题

### 生成质量标准

- 每个信息点具体可执行（含数字/步骤/替代方案），拒绝空泛形容词
- 专业术语必须口语转译（首次出现给生活化类比）
- 结尾必须有具体互动指令（"评论区扣 1"式，而非"欢迎讨论"）

## ④ 去AI味改写（必须）

AI 直出文案统一过一遍改写再交付，重点消除以下 AI 写作指纹：

| 指纹 | 修法 |
|------|------|
| not-X-but-Y 句式（"不是…而是…"） | 改为直接陈述，一段最多出现一次 |
| 强排比三连 | 保留最有力的一个，其余改写 |
| 破折号滥用 | 换逗号或拆句 |
| 夸大话术（"彻底改变/颠覆/必看"） | 换具体数字或事实 |
| 空洞总结段（"总之/综上"） | 删除，用行动指令收尾 |
| 开头模板腔 | 重写为具体场景或数字钩子 |

自检法：朗读开头 2 秒——如果像广告不像人说话，重写。改写不得改变事实与结构，只改表达。

## ⑤ 违禁词/合规检测（必须）

1. 宿主环境有检测工具（违禁词库/检测脚本）→ 全文跑一遍，命中词替换后复检至通过
2. 无工具 → 按 `platform-guide.md` 敏感词替换表人工过检（如"算命→传统文化""改运→调整状态"）
3. 各平台通用红线：医疗功效承诺、绝对化用语、封建迷信断言（改用"民俗说法/传统讲究"框架）、诱导性表述
4. 每条文案末尾附平台适用的免责声明

## ⑥ 一稿多发（可选）

母稿通过④⑤后，可按平台重构为多版本（每版仍需符合对应平台形态）：

| 目标平台 | 重构要点 |
|---------|---------|
| 口播视频（抖音/快手） | 四段式脚本，60-75s，钩子前置 |
| B站长视频 | 母稿扩密度：加考据/案例/体系图，标题带可搜索关键词 |
| 小红书 | 图文三件套，清单体，封面大字 |
| 公众号 | 富文本长文，小标题分段，结尾引导关注 |

原则：一稿多发是"重构"不是"复制粘贴"——每版开头、形式、互动方式按平台重做。

## 批量执行与交付

- 多选题批量生产：每条独立走完③④⑤，不合并省略
- 文件命名：`脚本_选题简称_YYYYMMDD.txt` / `图文_选题简称_YYYYMMDD.txt`
- 每条交付物注明：已过去AI味 ✓ / 已过违禁词检测 ✓（或列出待人工确认项）
- 建议回写：发布后按阶段五复盘各条收藏/互动比，反哺钩子类型与选题配比
